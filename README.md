# Axie Generals V28.2 — Gameplay Fix Pack

A browser-based Three.js prototype.

## Run locally
1. Extract the ZIP.
2. Open a terminal in this folder.
3. Run `python -m http.server 8000`.
4. Visit `http://localhost:8000`.

Internet access is required to load Three.js from jsDelivr.

## Controls
- Click a glowing battlefield marker to enter its encounter.
- Drag to pan the map; scroll to zoom.
- Use the battle panel to attack, guard, advance, use the general ability, or end a turn.
- Return to the map to reset the encounter.

## Scope and test status
This is a playable visual prototype, not a production-ready online game. It uses primitive 3D meshes and simulated turn-based combat; it does not include official Axie assets, multiplayer, persistent territory ownership, or full cinematic animation. Static JavaScript syntax and headless browser loading are checked during packaging; graphics performance depends on your browser and GPU.
